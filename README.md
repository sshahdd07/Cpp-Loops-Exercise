# C++ Loops Exercise

A beginner-friendly C++ project that demonstrates the use of loops and basic mathematical operations.

## Features

- Get a positive number from the user.
- Display numbers from 1 to the entered number.
- Calculate the sum of numbers.
- Display all even numbers.
- Calculate the factorial of the entered number.
- Display the multiplication table of the entered number.
- Validate user input.

## Concepts Used

- Variables and data types
- User input and output (`cin` and `cout`)
- Conditional statements (`if`)
- `for` loops
- Modulus operator (`%`)
- Basic mathematical operations

## How to Run

1. Download or clone this repository.
2. Open the `.cpp` file in a C++ IDE.
3. Compile and run the program.

## Example

If the user enters `5`, the program displays the numbers from 1 to 5, their sum, the even numbers, the factorial, and the multiplication table.

C++
